# COSY Studio Blueprint

Starter implementation for the COSY Studio blueprint.

## Available commands

- `npm run dev`
- `npm run lint`
- `npm run typecheck`
- `npm run build`
- `npm run prisma:generate`

## Included baseline

- Next.js 14 App Router with `src/` structure
- Strict TypeScript with `noUncheckedIndexedAccess` and `exactOptionalPropertyTypes`
- Tailwind design tokens for the warm brutalist palette
- Theme switching with `next-themes`
- Prisma schema and client generation script
- Three-column studio shell with chat, diff, and preview panels
